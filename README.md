# Visual Analysis of El Niño and La Niña Climate Phenomena

This project presents a scientific and educational visualization of the economic impacts of El Niño and La Niña. Using a world map with a scatterplot, it illustrates how these irregular Pacific events disrupt global economies through shifts in temperature, rainfall, and extreme weather.

## Start with a local server

1. Create venv:
```bash
python -m venv venv
```

2. Download live reload in your venv:
```bash
pip install livereload
```

3. Start the local webserver at localhost:8000:
```bash
python serve.py
```

**Note:** Auto-reload is enabled but doesn't always work reliably.
